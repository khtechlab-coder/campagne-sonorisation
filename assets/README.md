## partage.png
Fichier fourni par l'église, utilisé tel quel comme image Open Graph
(aperçu de partage WhatsApp, Facebook, etc.). Dimensions réelles :
1536x1024px, poids d'origine environ 2,1 Mo.

Remarque de performance (aucune action requise) : ce poids reste
correct pour un aperçu de partage, qui n'est chargé qu'une seule fois
par les serveurs de WhatsApp/Facebook lors de la génération de
l'aperçu, jamais par les visiteurs du site eux-mêmes. Si une réduction
de poids est un jour souhaitée, une compression sans perte de qualité
visible est possible, mais le fichier n'a volontairement pas été
modifié ici pour rester fidèle à l'original fourni.
